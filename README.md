## 🔒 Owner-Only Edit Controls
To ensure **"only myself can change it other can only see"**:
1. Click the **"Owner Access"** button in the navigation bar or bottom right floating action button.
2. Enter your **Master PIN** (Default: `1234`).
3. You can edit any information:
   - Personal bio, contact info, social links
   - University details & student ID
   - ACCA exam scores & new modules
   - Featured projects & GitHub repositories
   - Skills & proficiency percentages
   - Master PIN and JSON backup/restore
4. Click **"Save All Changes"** to persist updates immediately in your browser storage.
5. Click **"Lock & Return to Visitor View"** so anyone else visiting the site has read-only access.

## 🌐 Deploy to GitHub & Vercel
1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio release"
   git remote add origin https://github.com/ixtiyorjonnabiyev/Portfolio.git
   git push -u origin main
   ```
2. Deploy to Vercel:
   - Import your repository on [vercel.com](https://vercel.com).
   - Vercel automatically detects Next.js and deploys with continuous integration on every `git push`.
